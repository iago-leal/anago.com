# 01 — Fundamentos de Python

Ponto de partida. Antes de ciência de dados, Python. Este tópico cobre
a base da linguagem e serve de checagem de ambiente.

## Notebooks

- **`00-hello-data-science.ipynb`** — valida que seu ambiente está
  pronto: importa `numpy`, `pandas`, `matplotlib`, cria um pequeno
  dataset e gera seu primeiro gráfico.

## Tópicos previstos

- Tipos básicos: `int`, `float`, `str`, `bool`
- Listas, tuplas, dicionários, sets
- Controle de fluxo: `if`, `for`, `while`
- Funções e escopo
- Compreensões de lista (`list comprehensions`)
- Módulos e imports
