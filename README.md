# anago.com

Centro de estudo em ciência de dados.

Este repositório é um caderno de aprendizado organizado por tópico. Cada
pasta contém notebooks Jupyter com teoria, exemplos e exercícios. A ideia é
avançar do básico ao intermediário de forma incremental.

## Roadmap

1. **`01-fundamentos-python/`** — sintaxe, tipos, estruturas de dados, funções.
2. **`02-pandas-numpy/`** — manipulação de tabelas, séries, arrays numéricos.
3. **`03-visualizacao/`** — gráficos com matplotlib e seaborn.
4. **`04-estatistica/`** — descritiva, probabilidade, inferência.
5. **`05-machine-learning/`** — regressão, classificação, validação, scikit-learn.

## Como começar

Você precisa de Python 3.10+ e Jupyter instalados. A forma mais simples é
usar o [Anaconda](https://www.anaconda.com/download) ou `pip`:

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

Depois, rode o Jupyter a partir da raiz do repositório:

```bash
jupyter notebook
```

Abra `01-fundamentos-python/00-hello-data-science.ipynb` para o primeiro
notebook — ele valida que o seu ambiente está funcionando.
