# 03 — Visualização

Comunicar dados visualmente. Um bom gráfico resume mais que páginas de
números.

## Tópicos previstos

- Conceitos: eixos, escalas, tipos de gráfico
- `matplotlib`: figura, eixo, subplots
- `seaborn`: gráficos estatísticos de alto nível
- Boas práticas: cor, rótulos, honestidade visual
