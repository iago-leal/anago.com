# 04 — Estatística

A fundação matemática da ciência de dados. Sem estatística, um modelo é
só um oráculo opaco.

## Tópicos previstos

- Estatística descritiva: média, mediana, variância, quartis
- Distribuições de probabilidade
- Amostragem
- Testes de hipótese
- Intervalos de confiança
- Correlação vs causalidade
